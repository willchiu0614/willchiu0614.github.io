# 退稅記帳與圖片匯出設計

## 目的

讓旅客以店名及商品明細記錄同店同日消費，並將完整 Cash Japan 試算結果匯出成圖片，方便存入 iPhone 相簿或其他裝置留存。

## 範圍

- 商品清單模式新增店名輸入欄。
- 每筆商品新增品名欄，保留單價、數量、小計、新增及刪除功能。
- 總額仍為各商品含稅單價乘數量後加總，沿用既有退稅門檻、服務費、取整與匯率計算。
- 每家店使用一份 JSON；匯入檔案或貼上 JSON 後載入試算欄位，直接修改目前店家，再匯出／複製該店 JSON。
- 不使用帳號、Firebase、雲端資料庫或頁面內多筆記錄清單。表單只存在目前頁面，離開前須匯出。
- 新匯出 JSON 固定一店一筆；舊版多店 JSON 可匯入並逐店選取、另存。
- `data/` 僅保存 JSON schema 與操作說明。
- 新增「匯出記帳圖片」功能，範圍為完整 Cash Japan 計算區，不包含其他旅遊分頁。
- 直接輸入總額、輸入業者退款額兩種模式維持原狀。

## 互動與匯出

- 店名位於商品清單上方，商品名稱與單價、數量在同列；商品列可即時編輯及移除。
- 匯出內容包含店名、商品品名／單價／數量／小計、含稅總額、稅率、估算退稅額、服務費、取整結果、JPY／TWD 實退與匯率。
- 以 Canvas 從單店記錄資料繪製帳單 PNG，不擷取試算頁畫面；iPhone 可用分享面板儲存圖片，其他瀏覽器下載 PNG。
- 帳單表格列單價、數量、小計、預估逐件退稅、退稅後單價與台幣小字；公式列明單價×數量×稅率計算。
- 未稅總額未達 ¥5,000 時不顯示逐件退稅價或退稅後單價。
- 業者退款額模式不拆分退款；逐件金額只供估算，最終退款及服務費依整筆交易計算。
- 頁面上方提供檔案選擇、JSON 貼上與載入；匯入驗證後回填店名、商品與試算欄位。
- 新 JSON 包含 schema 版本、匯出時間及單一店家記錄；舊版多店 JSON 提供店家選取後逐店轉出。
- 匯出／複製一律使用目前表單資料；Clipboard API 不可用時選取上方 JSON 文字供手動複製。

## 實作與驗收

- 以 Canvas 2D 依帳單模板繪製圖片，不擷取頁面畫面，也不載入截圖套件。
- 單元測試確認商品名稱不影響金額加總，單價乘數及刪除後總額正確。
- 單元測試確認記帳記錄正規化、單店 JSON 序列化、舊版多店解析、達標逐件退稅估算及未達標隱藏金額。
- 瀏覽器測試確認店名、商品名即時呈現；新增、修改、刪除商品更新金額及公式。
- 瀏覽器測試確認檔案／貼上 JSON 載入、目前店家匯出／複製及舊多店逐店選取。
- 瀏覽器驗收帳單圖片由資料繪製、不是頁面截圖；行動裝置支援時打開分享面板，不支援時下載 PNG。
