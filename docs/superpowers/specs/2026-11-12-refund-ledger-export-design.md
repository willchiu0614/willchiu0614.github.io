# 退稅記帳與圖片匯出設計

## 目的

讓旅客以店名及商品明細記錄同店同日消費，並將完整 Cash Japan 試算結果匯出成圖片，方便存入 iPhone 相簿或其他裝置留存。

## 範圍

- 商品清單模式新增店名輸入欄。
- 每筆商品新增品名欄，保留單價、數量、小計、新增及刪除功能。
- 總額仍為各商品含稅單價乘數量後加總，沿用既有退稅門檻、服務費、取整與匯率計算。
- 以 Firebase Authentication 與 Cloud Firestore 提供跨裝置個人雲端記帳；每位登入者只可存取自己的資料。
- 新增記錄的儲存、載入、刪除，以及 JSON 備份匯出／匯入。
- 新增 `data/` 資料夾，保存記錄 schema、Firebase 設定範本與使用說明；靜態網頁不能自行寫回 GitHub Pages repo，線上資料以 Firestore 為準。
- 新增「匯出記帳圖片」功能，範圍為完整 Cash Japan 計算區，不包含其他旅遊分頁。
- 直接輸入總額、輸入業者退款額兩種模式維持原狀。

## 互動與匯出

- 店名位於商品清單上方，商品名稱與單價、數量在同列；商品列可即時編輯及移除。
- 匯出內容包含店名、商品品名／單價／數量／小計、含稅總額、稅率、估算退稅額、服務費、取整結果、JPY／TWD 實退與匯率。
- 將整個計算面板渲染成 PNG。iPhone 支援檔案分享時呼叫原生分享面板，由使用者選「儲存影像」；不支援時下載 PNG。
- 匯出時只排除操作按鈕，不隱藏記帳或試算資料；長清單完整輸出。
- 圖片產生失敗或分享不支援時提供可理解的訊息，並保留下載備援。
- 登入後可儲存目前記帳項目至個人 Firestore 記錄清單，並載入或刪除既有記錄；未完成 Firebase 設定時清楚提示設定狀態。
- JSON 備份包含 schema 版本、匯出時間與記錄清單；匯入前檢查格式，匯入後寫入目前登入者的雲端資料。

## 實作與驗收

- 以本機載入的 html2canvas 產生圖片，不依賴匯出時連線第三方 CDN。
- Firestore 使用者路徑採 `users/{uid}/refundRecords/{recordId}`，Rules 僅允許已登入使用者存取自己的記錄。
- 單元測試確認商品名稱不影響金額加總，單價乘數及刪除後總額正確。
- 單元測試確認記帳記錄正規化、備份匯出／匯入版本驗證與資料欄位完整。
- 瀏覽器測試確認店名、商品名即時呈現；新增、修改、刪除商品更新金額及公式。
- 驗證登入、保存、載入、刪除、JSON 備份／還原；若未提供 Firebase 專案設定，驗證無設定狀態提示且原計算機仍可使用。
- 瀏覽器驗收 PNG 有完整面板內容且長頁未裁切；行動裝置支援時打開分享面板，不支援時下載 PNG。
