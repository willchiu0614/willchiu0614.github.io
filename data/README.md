# Refund Ledger Data

每家店使用一份 JSON 檔，不使用 Firebase 或帳號登入。匯入的資料會載入試算欄位；修改後直接匯出或複製該店 JSON。表單只暫存在目前頁面，重新整理前請先匯出保存。

## 使用方式

1. 在試算上方貼入店家 JSON，或選擇該店的 `.json` 檔，再按「載入 JSON」。
2. 載入後直接修改店名、商品、稅率或匯率；按「匯出 JSON」下載更新後的單店檔。
3. 「複製 JSON」複製目前表單資料，可貼到記事本。若瀏覽器不允許自動複製，頁面會選取 JSON 文字供手動複製。
4. 「匯出帳單圖片」產生專用帳單版面 PNG，不是試算畫面的截圖。

JSON 格式與欄位定義見 `refund-record.schema.json`。新匯出檔只包含一家店的一筆記錄。舊版多店 JSON 可匯入，再從店家選單逐家載入、修改及另存為單店檔。

帳單圖片由店家與試算資料繪製，包含品項單價／數量／小計、逐件預估退稅公式、退稅後單價與台幣估值、整筆退款、服務費及日圓實退。只有同店未稅總額達 ¥5,000 時才列逐件退稅價與退稅後單價；未達門檻顯示未達訊息。業者退款額模式不將總退款拆分到商品。逐件數字為估算，最終退款與服務費仍以整筆交易計算。iPhone 支援檔案分享時可選「儲存影像」；其他瀏覽器會下載 PNG。
