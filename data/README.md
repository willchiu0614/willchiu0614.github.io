# Refund Ledger Data

記帳資料只透過 JSON 檔案匯入、匯出，不使用 Firebase 或帳號登入。清單暫存在目前頁面記憶體；重新整理或關閉頁面前，請先匯出備份。

## 使用方式

1. 輸入店名與商品，按「加入本筆」將目前試算加入頁面清單。
2. 「匯出 JSON」下載整份清單；若清單尚空，則匯出目前試算。
3. 「複製 JSON」複製相同備份內容，可直接貼到記事本。若瀏覽器不允許自動複製，頁面會顯示可手動全選的文字框。
4. 「匯入 JSON」驗證備份格式後，以檔案內容取代目前頁面的記帳清單。

JSON 格式與欄位定義見 `refund-record.schema.json`。匯出檔包含格式版本、匯出時間及多筆記錄；匯入不會合併，而是取代目前清單，避免不知情地產生重複資料。

「匯出記帳圖片」仍可將完整試算面板存為 PNG。iPhone 支援檔案分享時可選「儲存影像」；其他瀏覽器會下載 PNG。
